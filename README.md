# Uk_Labour_Market_Analysis
### Project Overview
An analysis of the UK labour market trends using data from the Office for National Statistics (ONS)

The project explores employment and unemployment across age groups, workforce jobs and vacancies by industry and an exploration of the relationship between job vacancies and unemployment.

### Tools Used

- SQL
- Google BigQuery
- Looker Studio

### Project Workflow

1. Collected publicly available market data from the ONS
2. Cleaned and transformed the datasets using SQL in BigQuery
3. Conducted exploratory analysis to investigate trends and answer research questions
4. Developed an interactive dashboard using Looker Studio
